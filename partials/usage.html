Three ways to command it.

01

Internal commands

/help /?Show the help message
/modelShow or switch the active model, live
/autoToggle autonomous mode on or off
/setSet any env var, no restart needed
/unsetRemove an env var
/refreshReload your config from disk
/clearClear the conversation history
/image <path> <prompt>Hand the model an image alongside your prompt
/byeExit the application

FLASH suggests slash commands as you type, so you never have to remember the exact one you're after.

/image suggests matching files and folders from disk as you type the path, filtered to supported image types (.png, .jpg, .jpeg, .webp, .gif, .bmp). Paths with spaces are quoted automatically, so they always parse correctly. It's the explicit form: you can also just mention an image by name in an ordinary prompt.

02

Direct shell execution

Run shell commands directly. No AI involved, no delay:

$!ls -la
$!git status
$!echo "Hello"

Every ! command runs with full interactive input live, a real terminal channel, not a simulation. Prompts, passwords or other sensitive info***, and editors just work.

03

Natural language

Just type what you want. If FLASH needs to see a file, look at an image, or run a command to answer you, it reaches for the right tool on its own. It can even search the web and show you exactly how it reasoned its way to an answer.

That includes images. Name one in an ordinary sentence and FLASH opens it: "Look at mockup.png and make a site that looks like it." The /image command is there when you want to be explicit, not a requirement.

By default, FLASH notifies you and asks for your input before running any command. Run /auto on for autonomous mode: no shell approvals*.

It runs on its own system prompt, tuned to get the most done in the fewest moves and to act safely**.

When the agent runs a command itself, input is cut automatically: a self-aware execution layer engineered so it can never stall waiting on a prompt it can't see. Real autonomy, not a frozen process.

*Autonomous mode lets FLASH run shell commands without asking first. That's risky: use it on machines and directories you trust.

**AI is unpredictable by nature. FLASH is designed to act safely, but neither FLASH nor its author is responsible for actions the model takes, review its output before you rely on it.

***Passwords or other sensitive info typed into a ! command never touch FLASH or the model. They go straight into your terminal's secure, masked input layer: invisible from the first keystroke. FLASH doesn't see them, doesn't log them, can't.
