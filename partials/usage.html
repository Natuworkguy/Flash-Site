Three ways to command it.

01

Internal commands

/help /?Show the help message
/modelShow the active model and Ollama host
/clearClear the conversation history
/byeExit the application
02

Direct shell execution

Run shell commands directly. No AI involved, no delay:

$!ls -la
$!git status
$!echo "Hello"
03

Natural language

Just type what you want. If FLASH needs to see a file or run a command to answer you, it invokes the shell tool on its own. It can even search the web and show you exactly how it reasoned its way to an answer.
