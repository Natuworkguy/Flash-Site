Not a chat box that happens
to sit in a terminal.

Thirteen things FLASH does on your machine, with your files, using your hardware.

Interactive AI chat

Chat with local or self-hosted models served by Ollama, straight from your terminal. No browser tab required.

Async sub-agents

Independent pieces of a job go to background sub-agents while the model gets on with something else. When one finishes, FLASH wakes the model with the answer and it reports back without you typing anything. /agents watches them all update live, /agents <id> opens one in full. It only wakes on an empty prompt, so a half-typed message is never taken from you, and it stops after three wakes in a row.

Visible plans

A multi-step task opens with a checklist, and each box gets ticked in place as that step actually lands. You watch the run happen instead of waiting for a wall of text at the end. /plan reprints the current list at any time; short tasks skip it entirely.

Switchable backend

Point FLASH at localhost or any remote Ollama server through a single config option. Scale from laptop to cluster without changing how you work.

Shell command execution

FLASH can call a shell tool and read the output itself, or you can fire off any command instantly with a ! prefix. The model sees those too: the command, its exit code, and its output ride along with your next message, so "why did that fail?" works right after one. Throwaway files it creates along the way, like scratch scripts or downloaded pages, stay in a dedicated scratch directory instead of cluttering your project, and get cleared out automatically when you exit.

VS Code aware

Run FLASH in VS Code's terminal and it works with the editor around it. An edit waiting on your yes opens as a side-by-side diff you can read properly, and the model opens a file at the exact line it's talking about instead of quoting a number at you.

Knows what just broke

/hook install adds a small zsh or bash hook, live in VS Code's terminal only, that records what you ran there and whether it failed. Ask "why did that fail?" and the model already knows which command and where, with nothing pasted. Commands starting with a space are skipped, secrets are redacted, and /hook remove takes it back out.

Context management

Automatic history trimming keeps every conversation inside the model's token limits, so long sessions never break.

Persistent memory

FLASH remembers across sessions, not just within one. Tell it to remember something and it sticks, ask it to recall and it searches everything it knows by keyword, tell it to forget and it's gone for good. No re-explaining your setup every time you open a new window.

Markdown support

Rich formatting for AI responses in the terminal: no raw asterisks, no wall of text, and LaTeX rendered as Unicode, so \frac{\pi}{2} arrives as π/2 instead of TeX source. FLASH can also generate real Word documents (DOCX) and PDFs when you need more than terminal text.

Web search and reasoning

FLASH doubles as a research assistant: it always knows the current date and can search the web through DuckDuckGo for fresh information, showing its reasoning as it works through a problem.

Images, in and out

Just name the file and FLASH looks: "Look at mockup.png and make a site that looks like it." No command needed. Or reach for /image <path> <prompt> to hand one over explicitly, with completion for matching files as you type, filtered to supported types (PNG, JPG, JPEG, WEBP, GIF, BMP) and paths with spaces quoted automatically. It hands pictures back the same way: a finished image is drawn inline in terminals that support it, and opened in your image viewer everywhere else.

A clean, simple interface

Engaging, uncluttered, and easy to follow: FLASH is built so anyone can understand exactly what's happening, no command-line experience required. Sit idle for a moment and a rotating tip sweeps into view letter by letter, cycling through example commands and prompts worth trying.

FLASH isn't vibe-coded. Every change is reviewed thoroughly by a real human before it ships.
