Built different. Built better.

Six pillars behind the most capable local AI shell available today.

Interactive AI chat

Chat with local or self-hosted models served by Ollama, straight from your terminal. No browser tab required.

Switchable backend

Point FLASH at localhost or any remote Ollama server through a single config option. Scale from laptop to cluster without changing how you work.

Shell command execution

FLASH can call a shell tool and read the output itself, or you can fire off any command instantly with a ! prefix.

Context management

Automatic history trimming keeps every conversation inside the model's token limits, so long sessions never break.

Markdown support

Rich formatting for AI responses in the terminal. No raw asterisks, no wall of text, just clean, readable output.

Web search and reasoning

FLASH can search the web through DuckDuckGo when it needs fresh information, and shows its reasoning as it works through a problem.

FLASH isn't vibe-coded. Every change is reviewed thoroughly by a real human before it ships.
