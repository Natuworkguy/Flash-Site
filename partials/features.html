Not a chat box that happens
to sit in a terminal.

Seventeen things FLASH does on your machine, with your files, using your hardware.

Interactive AI chat

Chat with local or self-hosted models served by Ollama, straight from your terminal. Rather have a window? The same agent runs in your browser too.

Flash Web

Run flash --web and the same agent opens in your browser. Replies stream in as they're written, tool calls fold away, and file changes show as colored diffs. Group chats into projects that work in their own folder, search every conversation, and watch the images and PDFs FLASH makes slide out beside the chat. Every action has a keyboard shortcut. Add --lan, scan the QR code, and pick it up on your phone.

Async sub-agents

Independent pieces of a job go to background sub-agents while the model gets on with something else. When one finishes, FLASH wakes the model with the answer and it reports back without you typing anything. /agents watches them all update live, /agents <id> opens one in full. It only wakes on an empty prompt, so a half-typed message is never taken from you, and it stops after three wakes in a row.

Visible plans

A multi-step task opens with a checklist, and each box gets ticked in place as that step actually lands. You watch the run happen instead of waiting for a wall of text at the end. /plan reprints the current list at any time; short tasks skip it entirely.

Switchable backend

Point FLASH at localhost or any remote Ollama server through a single config option. Scale from laptop to cluster without changing how you work. In the browser, switch between saved hosts from the model menu, with a dot showing which ones are up.

Shell command execution

FLASH can call a shell tool and read the output itself, or you can fire off any command instantly with a ! prefix. The model sees those too: the command, its exit code, and its output ride along with your next message, so "why did that fail?" works right after one. Throwaway files it creates along the way, like scratch scripts or downloaded pages, stay in a dedicated scratch directory instead of cluttering your project, and get cleared out automatically when you exit.

VS Code aware

Run FLASH in VS Code's terminal and it works with the editor around it. An edit waiting on your yes opens as a side-by-side diff you can read properly, and clears away once you've answered. The model opens a file at the exact line it's talking about instead of quoting a number at you.

Knows what just broke

/hook install adds a small zsh or bash hook, live in VS Code's terminal only, that records what you ran there and whether it failed. Ask "why did that fail?" and the model already knows which command and where, with nothing pasted. Commands starting with a space are skipped, secrets are redacted, and /hook remove takes it back out.

Context that lasts

History is measured against the model's real context window. When it fills, FLASH summarizes what's falling off instead of forgetting it, so long sessions keep their thread. /context shows how full it is, and /compact makes room on demand.

Learns as it works

FLASH remembers across sessions, and gets better at your work the more it does. It writes down how to do tasks that come up again as skills, reads the right one before it starts, and keeps what you've told it in view. A background review saves what's worth keeping, and it never touches the skills you wrote yourself. /skills shows what it has learned.

Precise edits, easy undo

FLASH changes a file by naming the exact text that changes, not by retyping the whole thing, so a one-line fix in a thousand-line file costs one line. Several changes land together or not at all. Changed your mind? /undo puts back every file the last turn touched.

Extensions

Add your own slash commands, tools the model can call, prompt text, and backgrounds, packaged as a GitHub repo: flash --extension-install github@you/your-ext. FLASH shows exactly what an extension adds and asks before installing it.

Markdown support

Rich formatting for AI responses in the terminal: no raw asterisks, no wall of text, and LaTeX rendered as Unicode, so \frac{\pi}{2} arrives as π/2 instead of TeX source. FLASH can also generate real Word documents (DOCX) and PDFs when you need more than terminal text.

Web search and reasoning

FLASH doubles as a research assistant: it always knows the current date and can search the web through DuckDuckGo for fresh information, showing its reasoning as it works through a problem.

Images, in and out

Just name the file and FLASH looks: "Look at mockup.png and make a site that looks like it." No command needed. Or reach for /image <path> <prompt> to hand one over explicitly, with completion for matching files as you type, filtered to supported types (PNG, JPG, JPEG, WEBP, GIF, BMP) and paths with spaces quoted automatically. It hands files back the same way: a finished image or PDF is drawn inline or opened in your viewer in the terminal, and slides out in a panel beside the chat in the browser.

A clean, simple interface

Engaging, uncluttered, and easy to follow: FLASH is built so anyone can understand exactly what's happening, no command-line experience required. Sit idle for a moment and a rotating tip sweeps into view letter by letter, cycling through example commands and prompts worth trying. A status line shows the model and how full the context is, long tool output folds to a few lines, and /background puts a pixel-art scene behind the prompt.

Keys that stay out of your way

Alt+Enter starts a new line. Up brings back earlier messages, even after a restart, and Ctrl+R searches them. Shift+Tab flips autonomous mode without leaving the prompt, and Ctrl+O opens any tool output that was folded away.

FLASH isn't vibe-coded. Every change is reviewed thoroughly by a real human before it ships.
