Don't want to touch a config file? FLASH has an easy slash-command interface for that: no JSON, no env files, unless you want them.

Prefer a text file? Configure FLASH with a ~/.flash.env file:

MODEL=llama3.1
OLLAMA_HOST=http://localhost:11434

See the repository's docs/CONFIGURATION.md for the full list of environment variables.
