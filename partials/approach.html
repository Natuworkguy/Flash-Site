OUR APPROACH

Built to be trusted
with your machine.

An agent that can run commands deserves a high bar. These are the ones FLASH holds itself to.

01

It asks before it acts.

By default, every command and every file edit waits for your yes. Autonomous mode is a choice you make, with /auto or Shift Tab, never a default.

02

It shows its work.

Plans tick off in place. Every tool call is on screen. Every file change shows as a diff. You always know what it did, and why.

03

You can take it back.

/undo puts back every file the last turn changed. Pages it makes open sandboxed, so their scripts never touch FLASH.

04

Your data stays yours.

The model runs on your hardware. No account, no API key, and nothing sent to a cloud model unless you choose a cloudbase tag, which says so first.

05

Honest about its limits.

Flash Onyx is tuned to say what it could not check instead of calling unrun work done. And this page says plainly where FLASH is not the right tool.

06

Open all the way down.

Every line of FLASH is MIT licensed on GitHub. Read it, change it, or ship your own extensions and skills on top.
